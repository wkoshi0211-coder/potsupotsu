# ぽつぽつ
画面いっぱいのひらがなを指でなぞる活動。ボタン・説明・設定・得点・音はありません。
基本46文字と風船・蜂・ちょうちょ・テントウムシ・カブトムシをランダムに提示。同じ文字は連続しません。
すべて触れると白い文字が完成し、1.8秒後に自動で次へ進みます。進行はブラウザ内に保存。別タブに移ると自動移行を一時停止します。
文字は縦横比を保ち画面内で最大表示します。
index.htmlを開くか node server.mjs で配信。node verify.mjs でロジック検証。iPad実機確認は別途必要です。

未タッチのイラストは個別の周期と方向で上下左右に微小に揺れます。雲になった後は静止します。端末の「視差効果を減らす」設定に対応します。

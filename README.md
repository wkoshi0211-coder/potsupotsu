# ぽつぽつ — なぞるひらがな
iPadの指操作で、小さなイラストを押したりなぞったりする静かな活動です。

## 使い方
index.html を静的Webサーバーで配信します。依存ライブラリ、ビルド、外部APIは不要です。
ローカル確認: node server.mjs
表示されたURLを開いてください。

- 風船・蜂・ちょうちょ。タッチで白い雲になり、最後にひらがなが現れます。
- 基本46文字をシャッフルし、同じ文字が連続しません。
- 「つぎへ」は完成前も利用可能。「ひとやすみ」で操作を一時停止できます。
- 設定で対象の細かさ、短いエフェクト、イラストのランダム切り替えを選べます。
- 進行と設定をlocalStorageに保存。個人情報や学習成績は収集しません。
- 音、得点、時間制限、自動の次課題移行はありません。
- iPad Safari実機での操作確認は別途必要です。日本語フォントによって配置が少し変わります。
